# Nazifa AI Android

Android APK source plus a Vercel backend for the Nazifa Mobile Notion Custom Agent.

## Download APK
Open GitHub **Releases**, select the latest **Nazifa AI APK** release, and download `Nazifa-AI.apk`.

## Connect the agent
Deploy the repository to Vercel and add `NOTION_API_KEY` and `NOTION_AGENT_NAME=Nazifa Mobile`. In the Android app, open Settings and enter the resulting HTTPS Vercel URL. Never put the Notion token inside the APK.
